## 压缩选择

- 一次隔离导出：Ultralytics 8.3.221、Torch 2.7.1 CPU、640、opset 12、simplify，输入 `[1,3,640,640]`，输出 `[1,37,8400]` 与 `[1,32,160,160]`。
- FP32 **47,375,205 B**；FP16 权重存储 **23,749,925 B**，超目标；动态 INT8 **12,374,423 B（12.37 MB）**；每通道 INT8 权重备选 **12,328,696 B**。
- 选用动态 INT8：ONNX Runtime 1.19.2 `quantize_dynamic`，QUInt8 权重，动态 uint8 激活，Conv / MatMul，per-tensor。不需要训练或校准集。保留 opset 12。
- 所有五张图的检出数量均与 FP32 相同。以下 IoU 在 160×160 原型网格上对匹配实例比较，**参照为 FP32 输出，不是人工真值**。

| 输入 | FP32 / INT8 片数 | 平均 mask IoU | 最低单片 IoU |
| --- | ---: | ---: | ---: |
| 握杯 | 8 / 8 | 99.40% | 96.25% |
| 双手叠放 | 6 / 6 | 96.97% | 87.50% |
| 长杏仁甲 | 5 / 5 | 98.69% | 95.29% |
| 交叉／侧向 | 2 / 2 | 95.83% | 91.67% |
| 弯指／深色甲 | 5 / 5 | 97.69% | 93.44% |

[FP32 与动态 INT8 轮廓图](quantization-comparison.jpg) · [全部候选的机器可读结果](model-comparison.json)。这组小样本中压缩未新增漏检，轮廓总体接近；不能从中推断完整数据集的 mAP / 分割精度。

## 首次加载

[网络测试原始记录](network-timing.json)。Chromium 模拟 **10 Mbps 下载、1 Mbps 上传、80 ms 延迟、空缓存**，桌面 CPU：

- 约 **21.96 秒**出现 8 片指甲的可编辑试色。
- 约 **37.66 秒**完成可选手指归属；该图没有手部关键点，已有分割结果继续可用。
- 首次核心资源约 **23.5 MB**；模型 12.37 MB，WASM 11.02 MB，另有少量 JS/MJS。手部模型随后额外约 16.2 MB。
- 本地无网络限速的整套测试，冷加载约数秒，后续每图约 2～3 秒；结果详见引擎 JSON。模型使用 Cache Storage 版本缓存并校验 SHA-256；缓存失败不阻止运行。

真实 iPhone 的下载、算力与内存还需设备验证；不能把桌面 WebKit 数字当作真机耗时。线上发布后的页面、模型资源及实际推理核验结果见 [线上验证](online-results.json)。
