# 美甲试色镜（PoC）

上传一张手背照片，自动定位指甲，试色号、图案、质感、点缀、甲型和长度，导出效果图和给美甲师的设计单。

在线试用：https://talentjay-ux.github.io/nail-tryon/

## 原理

- 手部关键点：Google MediaPipe Hands（21 点），在浏览器里本地运行，照片不上传。模型文件在 `mp/`（为了被静态托管当二进制文件下发，非 js/wasm 文件加了 `.wasm` 后缀）。
- 指甲位置：指尖关键点 + 远端关节确定方向和长度；宽度沿手指横向扫描皮肤边界量出手指粗细，按比例得出。
- 渲染：Canvas 2D，底色 → 图案 → 照片明暗 → 质感（曲面高光、镜面、猫眼、极光等）→ 点缀，边缘羽化。

## 已知局限

- 不是像素级指甲分割，手指侧转或甲型特殊时需要在"位置"页手动拖动、调宽窄角度。
- 长甲需要手动选长度。
- 需要整只手入镜才能识别。
